# struc2vec (third-party code)

This folder contains the reference implementation of struc2vec, used here only
as a baseline:

L. F. R. Ribeiro, P. H. P. Saverese, D. R. Figueiredo.
*struc2vec: Learning Node Representations from Structural Identity.*
KDD 2017. Original code: https://github.com/leoribeiro/struc2vec

All credit for this code goes to its authors; see the original repository for
its license. It runs in its own environment (`requirements_struc2vec.txt`).
